Pembagian Bilangan Bulat

Aturannya SAMA PERSIS dengan perkalian!

Konsep Dasar

Pembagian adalah kebalikan dari perkalian.
Jika 3 x 4 = 12, maka 12 : 4 = 3.

Rumus Tanda Pembagian

Tanda SAMA = POSITIF
(+) : (+) = Positif
(-) : (-) = Positif

Contoh: -10 : (-2) = 5

Tanda BEDA = NEGATIF
(+) : (-) = Negatif
(-) : (+) = Negatif

Contoh: -10 : 2 = -5

Cek Pemahamanmu

Negatif dibagi Positif hasilnya Negatif.
Tanda sama, hasilnya Positif.
